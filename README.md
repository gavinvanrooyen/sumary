# Sumary × Gavin — Interview Case Study Microsite

A mobile-first interactive case-study presentation designed for the Sumary Forward Deployed Accountant interview.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy to Netlify

Drag the folder into Netlify, or connect the GitHub repository. No build command is required and the publish directory is the project root.

## Controls

- Scroll to move through the story.
- On desktop, `←` / `→` / `↑` / `↓` / `Space` navigate between sections.
- Click the timeline cards to change the 90-day targets.
- Click the three automation cards, then `Run check ↗` to trigger the interactive ledger demo.

## Notes

The pilot metrics shown in the interactive plan are explicitly illustrative demo values, not Sumary/client results. The Sumary × Gavin treatment is an interview presentation identity, not an official Sumary product screen.
